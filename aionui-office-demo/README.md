## 三个提示词(直接复制)

**① Excel 数据清洗+分析看板**(ClaudeCode 会话,附上 `Q2销售流水.xlsx`)

```
帮我处理这份Q2销售流水:
1. 先做数据体检:找出重复订单、销售额空缺、城市名称不统一(比如"北京"和"北京市")这类问题,列给我看
2. 然后直接修复:重复的删掉,城市名统一,缺的销售额用数量×单价补上
3. 新建一个工作表做数据透视表:按城市和产品类别汇总销售额
4. 再建一个"分析看板"工作表:各月销售趋势折线图、各渠道占比饼图、产品类别对比柱状图,顶部放本季度总销售额、订单数、客单价三个关键数字
```

**② Word 正式报告**(新会话,附上清洗后的 Excel)

```
基于这份Excel的分析结果,写一份《2026年Q2销售分析报告》Word文档:
- 正式商务风格,封面有标题、日期、"星河科技销售部",封面后面带自动目录
- 章节:业绩总览、分城市分析、分渠道分析、产品表现、问题与建议
- 所有数字必须引用Excel里的真实数据,关键对比配图表
- 页眉写"星河科技",页脚放页码,全文加"内部资料"水印
```

**③ 3D动画PPT**(新会话,附上 Word 报告 + `椅子3D模型.glb`)

```
把这份Q2销售分析报告做成一份10页左右的汇报PPT:
- 深色科技风,背景用深蓝#1A1A2E,亮青色点缀,数据用大字号
- 页与页之间全部用Morph平滑变形转场,每页元素有进场动画,关键数字加强调动画
- 讲人体工学椅销量第一的那一页,插入我给你的椅子3D模型,做旋转展示
- 最后一页放Q3目标,三个目标数字逐个弹出
```

**④ 修改类提示词**(生成后接着说)

```
第五章问题与建议里,加一条关于杭州线下门店销量偏低的建议,语气委婉一点
```
