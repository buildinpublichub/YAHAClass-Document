# 會議紀錄整理

## 輸出格式（照這個順序，不要多加段落）

1. **會議資訊**：日期、與會者（筆記裡沒寫就標「未提供」，不要自己編）
2. **三句話摘要**：這場會決定了什麼
3. **決議事項**：條列，每條一句
4. **待辦清單**：表格，欄位是「事項｜負責人｜期限」。沒講到負責人或期限就寫「待確認」
5. **LINE 群組通知**：100 字以內，開頭「各位好～」，列出每個人的待辦和期限，結尾「有問題直接回這裡」

## 規則

- 用正體中文、台灣用語
- 日期寫成「10月23日（五）」這種格式
- 筆記裡沒出現的事情一律不准補，寧可寫「待確認」
