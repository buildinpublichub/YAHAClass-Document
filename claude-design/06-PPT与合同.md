# 06 · PPT 与合同文档

> 对应视频章节：5/7 PPT跟合同

设计系统在，这两样是顺手的事——**颜色、字体、版式全部自动从设计系统里长出来，一个字都不用调**。

## PPT（Slides）

首页 → **Template** 选 **Slides** → Design system 选好。

```
帮我做一份可以拿给客户看的PPT，介绍我们不同的热水器选择。

请一并给我图片的生成提示词，我来把图补上。
```

问卷回答（视频里的选择）：

| 问题 | 回答 |
|------|------|
| 规格价位 | 晚点再给，先留占位符 |
| 产品数量 | 3-4 个产品 |
| 类别 | 无水箱＋有水箱两类 |
| 受众 | 屋主 |
| 用途 | 帮客户对比选购 |
| 呈现方式 | 用对比表格 |
| 篇幅 | 短版 6-8 页 |
| 必备页 | 封面＋对比表＋联系页 |

细节：规格价位说「晚点再给，先留占位符」——现在要证明的不是这份 PPT 能不能用，是**它长得对不对**。图片提示词会写在讲者备忘稿里，需要时把图拖进槽位。可直接导出 PPTX。

## 合同（Document）

首页 → **Template** 选 **Document** → Design system 选好。

```
帮我做一份基本的施工同意书，客户签了名我们就能开工。
要留几个可以替换的地方：客户名字、服务项目明细。
整体保持标准合同的样子，但加上一点我们的品牌元素。
```

## 🔴 坑：版面溢出——浏览器里看着对，不代表印出来对

生成的合同**右边被切掉了**：表格的 Amount 栏、Estimated total 的金额全部溢出到纸外面。这份东西是要打印给客户签字的，右边切掉就是一张废纸。**只要是要打印的东西（合同、发票、估价单），都要检查页边距。**

修复提示词：

```
文档的版面有问题：内容超出了页面宽度，右边被截断了。

具体：
- Scope of work 表格的 Amount 栏、Estimated total 的金额，都溢出到纸张右边缘外面
- Contractor 卡片右侧的填写下划线也超出了页面
- 整个内容区比纸张宽

请修正版面：
1. 内容区宽度必须完全落在页面（Letter / A4）的可打印区域内，左右各留标准页边距（约 20mm）
2. 表格宽度设为 100% 容器宽度，不要溢出
3. 所有填写用的下划线，长度要根据剩余空间自适应，不能撑破容器
4. 检查每一页，确保没有任何内容被裁掉

这份文档是要打印出来给客户签的，右边被切掉就废了。
```

### 修 bug 提示词的写法

不要只讲「版面跑掉了，帮我修」。要讲三件事：

1. **哪里坏了**——溢出的三个地方一个一个点出来
2. **要修成什么样**——落在可打印区、左右 20mm 边距、表格宽度 100%
3. **为什么**——这是要打印给客户签字的。**把用途讲清楚，它才知道该有多严格。**

## ⚠️ 免责提醒

AI 生的合同只能当草稿、当格式，**一定要给律师看过再用**——它不懂你当地的法规。里面默认的金额、天数也要自己改成对的。
