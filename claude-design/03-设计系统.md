# 03 · 建立设计系统（Claude Design）

> 对应视频章节：2/7 建立设计系统 → 把这些喂回设计系统

入口：Claude Design 右侧 **Design systems** 分页 → **Create design system** → 弹窗选 **Create here**（从零开始走这条；下面那条是给已有 React 组件库的人，在 Claude Code 里跑指令同步代码）。

表单字段很多，但**只需要填三个**，GitHub / Figma 那些都是选填。

## 字段一：Company name and blurb

```
Ironclad Plumbing：一家位于美国密歇根州西南部的水电维修公司，服务本地社区，主打可靠、快速、值得信任。
```

这段是整个设计系统的**身份**——后面所有颜色、字体、语气都从这段推。写得越具体，生出来越不像通用模板。

## 字段二：Add fonts, logos and assets

把 [01](./01-logo生成.md) 拿到的 **真 SVG logo** 拖进上传区。

## 字段三：Any other notes?

```
字体：标题用 Fraunces（Semi Bold），内文用 Karla（Regular）。

配色：
主色 深靛蓝 #1F3A5F
强调色 暖陶土 #C86B3C
背景 米白 #F5EFE6
文字 近黑 #2B2B28

我上传的 logo 是灰色的，请把它套用成上面这组品牌配色，并生出各种变体。

请帮我做一份完整的品牌指南，包含网页组件、动态效果的构想、logo 的各种变体、
背景配色的用法、以及什么时候该用哪种字体。

现在先不要做出实际的网站，我只想先看到之后可以拿来做资产的所有组件。
```

这段 notes 讲了三件事，每件都有讲究：

1. **字体跟配色**——上一步 Claude 帮选的，直接贴。
2. **改 logo 颜色**——Lovart 给的 logo 是灰的，跟品牌色对不上。因为是真 SVG（67 条路径），Claude 可以直接进去改每条路径的颜色。**如果是 PNG，这步做不了**，六个变体一个都生不出来。
3. **「先不要做网站」最重要**——不讲它会直接生一个网站，变成一次性成品。我们要的是一套**标准**，标准立好后面全部复用。

## 生成后

- 点 **Generate**，跑约 5 分钟，可以走开但**分页别关**。
- 结果包含：Readme、品牌色（自动扩展成整套色阶）、字体规则、**Logo 六个变体**（靛蓝／深底反白／陶土橙／纯图标／App 圆角图标／Badge）、动态效果构想、全套组件（按钮、输入框、卡片、Callout、Badge…）。
- Readme 里有一句关键的话：`All brand color variants in assets/ are recolored programmatically from this single file.`——六个变体是从那**一个源文件程序化重新上色**出来的，这就是为什么必须是真 SVG。
- 右上角默认勾选 **Published** ＋ **Currently org default**：团队里任何人开新项目都会自动套用这套设计系统。
