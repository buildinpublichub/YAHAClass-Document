# 04 · 做网站（Prototype）＋ 网站图片

> 对应视频章节：3/7 做网站

首页输入框 → **Template** 选 **Prototype** → **Design system** 确认选到你建好的那个（不选它就随便给一套，前面就白做了）。Wireframe 是黑白线框、不套品牌，要成品走 Prototype。

## 网站生成提示词

```
帮我做一个单页的落地页网站。

版面：
- 最上面是主视觉区，右边放一个免费估价的表单，左边讲我们是本地的、值得信赖的水电公司
- 下面接服务项目区
- 再下面是服务地区区块
- 最下面再放一次同样的估价表单，但换一个排版方式，给一路滑到底的人用

导航列：
- 首页锚点连到主视觉
- 服务是一个下拉菜单，点进去每个服务都有自己的独立页面

图片：
- 所有需要图片的地方先放占位符，然后给我每一张图的生成提示词，
  以及它需要的长宽比。我等一下会把图生好再给你。
```

这段 prompt 三个值得学的地方：

1. **不说「做一个好看的网站」**——版面从上到下讲清楚，AI 不会通灵，讲得越具体它猜得越少。
2. **底部再放一次表单**——滑到底的人是真有兴趣的人，不能让他滑回去找表单，这是转换率基本功。
3. **叫它先放占位符＋给出每张图的提示词和长宽比**——不用自己猜要生什么图、生多大，它直接开菜单。

## 它会先问问题（好事，代表不乱猜），视频里的回答

| 问题 | 回答 |
|------|------|
| 服务项目 | 漏水抢修、热水器安装更换、管路重铺 |
| 电话 | 先用占位符 |
| 信任标章 | A+评级、超过500条评价平均4.7星、本地家族经营 |
| 服务地区 | 卡拉马祖、波蒂奇、巴特克里克、三河、波帕 |
| 表单字段 | 姓名、电话、email、地址、需要的服务、多久内需要、留言 |
| 是否现在就做服务子页 | 是 |
| 可调整的选项 | 全部勾上 |

## 网站图片（Lovart）

生成后它会在聊天栏给出图片清单：**文件名、提示词、长宽比全都写好**。⚠️ 两个坑：

- **长宽比别搞混**：只有 `hero-bg` 是 16:9，其余四张都是 4:3。
- **文件名照抄，一个字别改**——名字是它自己取的，对上了它才知道每张放哪。
- 图别生太大：下载选 WEBP 或别选 4K，几 MB 一张会拖慢网站。

### 1. `hero-bg.jpg` — 16:9

```
A friendly licensed plumber in a clean navy work shirt shaking hands with a homeowner on the front porch of a modest Midwestern house, warm late-afternoon light, a service van softly out of focus in the driveway, natural and candid, warm tones.
```

### 2. `service-leak.jpg` — 4:3

```
Close-up of a plumber's hands using a wrench on a copper pipe fitting under a kitchen sink, small water droplet visible, warm interior daylight, shallow depth of field.
```

### 3. `service-water-heater.jpg` — 4:3

```
A plumber installing a new water heater tank in a clean residential basement/utility room, checking connections, warm work light, professional and tidy.
```

### 4. `service-repiping.jpg` — 4:3

```
Fresh copper and PEX water lines neatly run along floor joists in a home under repiping, clean workmanship, warm natural light.
```

### 5. `service-area-map.jpg` — 4:3（插画地图，不是照片）

```
A warm, simple illustrated map of Southwest Michigan marking Kalamazoo, Portage, Battle Creek, Three Rivers, and Paw Paw with terracotta pins on a cream background, indigo roads, tasteful and minimal.
```

## 把图塞回网站

回到 Claude Design **同一个对话**，五张图全部拖进去：

```
图片生好了，文件名跟你给的占位符一致。请把它们放到对应的位置。
```

文件名对上，它自己会摆——不用一张张解释哪张放哪。
