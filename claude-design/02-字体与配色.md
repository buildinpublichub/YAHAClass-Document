# 02 · 字体与配色（普通 Claude 对话）

> 对应视频章节：2/7 建立设计系统 → 挑字体跟配色

这一步**不用在 Claude Design 里问**——只是查资料，开一个普通 Claude 对话、模型选 Sonnet、思考强度中等就够了，省额度。

## 第一步：选字体

```
这是我的公司简介：一家位于美国密歇根州西南部的水电维修公司，服务本地社区，主打可靠、快速、值得信任。请列出适合这个品牌的Google字体组合，给我四组不同的标题字体加内文字体搭配。我不要太老套的，也不要太前卫的。直接告诉我最好的四个选择。
```

细节：**特别指定 Google 字体**——免费、可商用、做网站直接能用，不用另外买授权。

它会问要不要做可视化对比预览，回 `好`。

## 🔴 坑：中文预览全部长一样

预览生出来后，四张卡的中文标题看起来几乎一模一样——因为 **Google 西文字体不含中文字符，全部 fallback 到系统字体**（显示的其实都是同一套苹方）。修复只要一句话：

```
预览里的标题请改用英文公司名 Ironclad Plumbing，内文也用英文，这样才看得出四组Google字体的真实差别。中文的部分先不用管。
```

视频里最终选了**方案一：Fraunces（标题）＋ Karla（内文）**——手工感＋干净无衬线，专业但不冷漠。

## 第二步：选配色（同一个对话继续）

```
字体我选方案一。现在请给我四组配色方案，要能传达值得信任的感觉，但又要保有小镇本地公司的亲切感，不要太企业化。
```

它会直接生出带真实卡片（标题＋标语＋按钮）的色卡预览，并给推荐。

## 第三步：拿色码

```
方案一的四个色码给我，直接给 hex。
```

视频里最终拿到的一组：

| 用途 | 名称 | Hex |
|------|------|-----|
| 主色 | 深靛蓝 | `#1F3A5F` |
| 强调色 | 暖陶土 | `#C86B3C` |
| 背景 | 米白 | `#F5EFE6` |
| 文字 | 近黑 | `#2B2B28` |

字体：标题 **Fraunces**（Semi Bold）／内文 **Karla**（Regular）。这些下一步要贴进设计系统。
