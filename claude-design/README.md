## 🔑 视频里最重要的几个坑（速查）

1. **Lovart 直接下载的 SVG 是假的**——是 PNG 包了层 SVG 壳。要**先矢量化（Vectorize）再导出**。验证方法：文件应该只有几十 KB，用文本编辑器打开搜 `<path` 能搜到才是真的。→ [`01`](./01-logo生成.md)
2. **字体预览用中文会全部长一样**——Google 西文字体不含中文，全部 fallback 成系统字体。预览要用英文。→ [`02`](./02-字体与配色.md)
3. **建设计系统时明确说「先不要做网站」**——不说它会直接生成品，你要的是可复用的标准。→ [`03`](./03-设计系统.md)
4. **图片文件名照它给的抄，一个字别改**——名字对上它才知道每张图放哪。→ [`04`](./04-网站生成.md)
5. **多张分镜图要传参考图**——模型没有跨图记忆，不传参考图人物会换人。生视频提示词里要加「不要对白」。→ [`05`](./05-广告分镜.md)
6. **要打印的文档必须检查页边距**——浏览器里看着对，不代表印出来对。→ [`06`](./06-PPT与合同.md)
7. **五段交接 prompt 一次性贴给 Claude Code**——一段一段跑，它看不到全貌，目录结构从一开始就会错。→ [`07`](./07-ClaudeCode整合与部署.md)
8. **Netlify 表单功能默认是关的**——开启 form detection 之后要**重新部署一次**才会生效。→ [`07`](./07-ClaudeCode整合与部署.md)

## 💰 开始之前

- Claude Design 入口：`claude.ai/design`（或 Claude 桌面版侧边栏），需要 **Pro / Max / Team / Enterprise** 付费方案。
- 目前是 research preview，界面和功能可能与视频略有出入。
- 跑一次完整设计系统约 5 分钟，很吃用量额度；Pro 方案跑两三个完整项目可能就碰上限。
- 素材生成用 Lovart（图片＋视频都能生，logo 能出真 SVG），有每日免费额度，视频素材耗额度较重。
