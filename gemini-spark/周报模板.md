# 周报模板（Gemini Spark实操视频配套）

> 视频里2/6段用的主管周报模板。复制下面整段，贴进Google Docs，
> 放到你的`Spark OS/Spark模板/`文件夹，命名「周报模板」即可。

```
【主管周报】第__周（__月__日～__月__日）

一、本周结论（先说重点，3句以内）
1.
2.
3.

二、各组进展
▍后端组
- 完成：
- 进行中：
- 延误/变更：

▍前端组
- 完成：
- 进行中：
- 延误/变更：

▍运维组
- 完成：
- 进行中：
- 延误/变更：

三、风险与求助
- 风险：
- 需要主管决策/协调：

四、下周关键事项（最多3条）
1.
2.
3.
```

组名可以改成你自己团队的分组，段落结构不变，Spark认的是结构。
